SALAMTAK WEB - QUICK SETUP GUIDE
=================================

The website is now ready to use! It uses a file-based database system that mimics Firestore,
so it works exactly like your Flutter app but without needing MySQL.

SETUP STEPS:
------------

1. Make sure you have a web server running (XAMPP, WAMP, or built-in PHP server)

2. The website is located at: C:\New folder\htdocs\swebsite\salamtak\salamtak_web

3. If using XAMPP/WAMP:
   - The website should be accessible at: http://localhost/salamtak/salamtak_web/

4. If using PHP built-in server:
   - Open terminal in the salamtak_web folder
   - Run: php -S localhost:8000
   - Access at: http://localhost:8000/

5. Data Storage:
   - All data is stored in JSON files in the 'data/' folder
   - This folder is created automatically on first run
   - Users and reports are stored separately (users.json, reports.json)

TROUBLESHOOTING:
----------------

1. If you see "Permission denied" errors:
   - Make sure the web server has write permissions to the salamtak_web folder
   - On Windows, right-click folder > Properties > Security > Edit > Add write permissions

2. If images don't upload:
   - Check that the 'uploads/' folder exists
   - Check folder permissions

3. If data doesn't persist:
   - Check that the 'data/' folder can be created
   - Check write permissions

4. To reset all data:
   - Delete the 'data/' folder
   - Refresh the website - it will recreate with default admin/user

ACCESSING THE WEBSITE:
----------------------

Option 1 - Using existing web server:
   http://localhost/salamtak/salamtak_web/

Option 2 - Using PHP built-in server:
   1. Open PowerShell/CMD
   2. Navigate to: cd "C:\New folder\htdocs\swebsite\salamtak\salamtak_web"
   3. Run: php -S localhost:8000
   4. Open browser: http://localhost:8000/
