## Design Consistency:

### Color Palette:
- **Primary Gradient**: Purple (#667eea to #764ba2)
- **Card Background**: White with 95% opacity + backdrop blur
- **Text on Gradient**: White
- **Text on Cards**: Dark (var(--text-primary))
- **Accent**: Primary blue (var(--primary))

### Glass-morphism Effects:
- Back arrow: `rgba(255, 255, 255, 0.2)` with `backdrop-filter: blur(10px)`
- Cards: `rgba(255, 255, 255, 0.95)` with `backdrop-filter: blur(20px)`
- Border: `1px solid rgba(255, 255, 255, 0.3)`
- Shadow: `0 20px 60px rgba(0, 0, 0, 0.3)`

### Typography:
- **Page Title**: 32px, weight 800, white color
- **Card Title**: 24px, weight 800, dark color
- **Subtitle**: 14px, semi-transparent
- **Body**: 14px, standard weight

### Spacing:
- Card padding: 32px 28px
- Border radius: 12px (buttons), 20px (cards)
- Container padding: 80px 20px 60px
