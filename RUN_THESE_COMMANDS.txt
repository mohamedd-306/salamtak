========================================
   TROUBLESHOOTING
========================================

Problem: "firebase: command not found"
Solution: Install Firebase CLI first:
  npm install -g firebase-tools

Problem: "Failed to authenticate"
Solution: Run firebase login again:
  firebase login --reauth

Problem: "No project selected"
Solution: The .firebaserc file is already created,
  just run the deploy command again
