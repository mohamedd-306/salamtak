========================================
  FIX REPORT IMAGES - 2 SIMPLE STEPS
========================================

STEP 1: LOGIN TO FIREBASE
--------------------------
Open Command Prompt (CMD) and run:

cd "c:\New folder\htdocs\swebsite\salamtak - Copy"
firebase login

(Browser will open, login with: mr121150@gmail.com)


STEP 2: DEPLOY RULES
---------------------

firebase deploy --only storage

Done! ✅


STEP 3: RESTART APP
--------------------
Close the Flutter app and run it again.
Report images should now load!
